# OpenGoldBox

An open-source engine for the classic "Gold Box" style of turn-based party CRPGs (SSI, 1988–1993).

**Goals**

- Play **any module**: modules converted from original games you own, and new modules made by the community.
- **Bring your own files.** OpenGoldBox ships no original game data. A built-in importer converts your own copies
  into the open module format on your machine.
- Faithful first: imported games play like the originals. Quality-of-life features from the later games and
  companion tools (heal-the-party FIX, automap, faster combat, better menus) are options you switch on.
- A **character manager** that moves characters between games and modules, following each sequel's transfer rules.
- An open, documented **module format** and, later, an editor for making new adventures.

**Status:** early planning. Nothing playable yet.
